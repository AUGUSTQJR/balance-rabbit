# 余额兔 · iOS 安装说明（Scriptable 小组件版）

把你桌面版「余额兔」能看的数字搬到 iPhone：余额、今日花费、近 7 天花费 + 柱状图、Token、模型用量。
**不用网页登录，不用每次刷新**——主屏/锁屏组件自动更新，点一下组件看明细。

- 脚本：`余额兔.js`（本目录，版本 v1.4.0）
- 依赖：App Store 免费 App **Scriptable**
- 系统：iOS 16 及以上（锁屏组件需要 16；主屏组件更早就行）
- 费用：0 元，不用开发者账号，不用连电脑

---

## 一、准备 API Key（一次性）

Key 在 Mac 上，先说清楚：**它相当于账户密码，别发微信/邮件，别截图**。

在 Mac 终端执行（把 Key 复制到剪贴板，不会显示出来）：

```bash
awk '/RABBIT_API_KEY/{print $2}' ~/.dsh/.credentials.yaml | pbcopy
```

如果你的 Mac 和 iPhone 登录同一个 Apple ID、开了蓝牙/Wi-Fi，接下来手机上直接「粘贴」即可（通用剪贴板）。

---

## 二、把脚本装到手机（约 2 分钟）

1. iPhone 打开 App Store，搜 **Scriptable**（开发者 Simon Støvring），免费安装。
2. 把 `余额兔.js` 的内容弄到手机，二选一：
   - **推荐：通用剪贴板**。Mac 终端执行下面命令，脚本全文进剪贴板，手机上直接长按「粘贴」：
     ```bash
     cd ~/Documents/deepseek-harness/rabbit && pbcopy < ios/余额兔.js
     ```
     或者用文本编辑器打开 `余额兔.js` 全选复制。
   - 或者把 `余额兔.js` 存到 iCloud Drive，在 Files 里选中该文件 → 分享 → 用「拷贝」到剪贴板（iOS 只能整篇复制，可用「快速查看」→ 全选复制）。
3. 打开 Scriptable → 右上角 **+** → 底部把默认代码全选删掉 → **粘贴** → 顶部把脚本名改成 `余额兔` → 点 **Done**。

> 小技巧：在 Scriptable 里长按脚本可改名、复制；脚本名建议就叫「余额兔」。

---

## 三、首次运行：填 Key + 拉数据

1. 在 Scriptable 里点一下「余额兔」脚本运行。
2. 弹出「填写 rabbitj.top API Key」→ 粘贴刚才复制的 Key（带不带 `Bearer ` 前缀都行）→ 保存。
3. 第一次约 **1~2 秒**（并发查询 7 天汇总，不再翻几千条流水），然后弹出明细表：
   - 余额 / 今日花费 / 近 7 天花费 / 今日与 7 天 Token
   - 每日花费（7 行，含次数与 Token）
   - 模型用量（按 7 天花费排序，前 8 个）
   - 操作：复制余额、打开 rabbitj.top、显示 Key 尾号
4. 关掉明细表即可。数据缓存在本机，之后每次刷新同样只要 1 秒左右。

> **加组件前先手动运行一次**（就是上面第 1~3 步）。这样组件第一次渲染会直接用本地缓存，不等网络，
> 在任何网络环境下都不会超时。

---

## 四、加到主屏 / 锁屏

**主屏组件：**

1. 长按主屏空白处 → 左上角 **+** → 搜 **Scriptable** → 选 **中号（Medium）** → 添加。
2. 添加后**长按组件 → 编辑小组件** → Script 选「余额兔」。
3. 中号显示：余额 + 今日 + 7 天 + Token + 7 天柱状图 + 最常用模型；
   小号只有数字（余额/今日/7天），看你要不要柱子。

**锁屏组件（iOS 16+）：**

1. 锁屏长按 → 自定 → 点锁屏下方组件区域 → 选 Scriptable。
2. 三种都支持：矩形（余额+今日+7天）、圆形（只剩金额）、单行（一行文字）。

**点组件**：打开 Scriptable 并显示明细（顺带刷新一次数据）。

---

## 五、点一下立刻查（不打开 App 也行）

用「轻点背面两下」当快捷键：

1. 打开「快捷指令」→ 新建快捷指令。
2. 添加操作 **运行脚本**（Scriptable）→ Script 选「余额兔」；
   **关闭**「在 App 中运行」（关键，这样不会跳 App）。
3. 再添加操作 **显示结果**（或「显示通知」），把输入设为上一步的 **脚本输出**。
4. 给快捷指令起名「查余额」→ 保存。
5. 设置 → 辅助功能 → 触控 → **轻点背面** → 轻点两下 → 选「查余额」。

之后双击手机背面，直接弹「余额 ¥xx · 今日 ¥x · 7天 ¥x · Token x」。

> 想再省事：把「查余额」也加到锁屏/主屏，或对 Siri 说「查余额」（Siri 里选这个快捷指令）。

## 六、刷新是怎么工作的（重要）

| 项目 | 说明 |
|---|---|
| 组件自动刷新 | 脚本请求每 10 分钟刷一次，实际由 iOS 调度，通常 **15~30 分钟**更新一次 |
| 点组件 / 运行脚本 | 立即刷新（约 1 秒） |
| 查询方式 | 组件刷新只发 **1 个请求**：`/v1/account/spending` 一次拿余额 + 7 天逐日花费/请求/Token；App 内再补 1 页流水（累计请求 + 模型分布）+ 每个模型 1 个 7 天汇总 |
| 数据来源 | 官方账户接口 `/v1/account/spending`、`/v1/account/balance`（与网页端同源、实时）；接口不可用时自动回退旧 `/v1/usage/summary` 按天汇总 |
| 流量 | 组件 ≈ 1 个请求、几 KB、0.1~0.3 秒；App 内 3~10 个请求、1 秒内 |
| 计费 | 只读查询，不消耗余额 |

余额低于 **¥20** 时，组件里的数字会变红（只改颜色，不发推送——要推送见下面"可选"）。

**可选：低余额推送**
快捷指令 → 自动化 → 个人自动化 → 时间（比如每天 9:00）→ 运行「查余额」中的「运行脚本」→ 加「如果」余额 < 20 → 显示通知。
（需要把「显示结果」换成「显示通知」，并在脚本输出里带上余额。）

## 七、常见问题

**组件显示「未配置 API Key」**
点组件 → 运行脚本 → 粘贴 Key。若 Key 之前填过但被系统清了，重新填一次即可。

**组件显示「更新失败」但还有数字**
网络问题，显示的是本地缓存（带 ⚠️ 标记），联网后自动恢复；刷新方式就是点一下组件。

**运行时报 `Received timeout when running script.`**
v1.4.0 已把组件端压到 **1 个请求**（官方 `/v1/account/spending`，约 0.1~0.3 秒），
并加了 5 秒硬超时兜底：到点就用手头缓存出画面，网络再卡也不会被系统杀掉。若还报这个错：

1. 重新复制 `余额兔.js`，确认第 14 行是 `const SCRIPT_VERSION = "1.4.0";`；
2. **先在 App 里手动运行一次**，明细最底部应显示「余额兔 v1.4.0」；
3. 手动运行正常后 3 分钟内看组件：这时直接读缓存，**一个请求都不发**；
4. 仍超时：把 `诊断.js` 粘成另一个脚本，加一个小号组件选「诊断」（它不联网）。
   诊断组件能显示「✅ 组件能运行」= 组件环境没问题，把你看到的报错发我；
   连它都超时 = Scriptable 组件环境问题：重启手机 → 删除组件重加 → 更新/重装 Scriptable；
5. 顺带确认加的是**主屏**组件（排查时用中号）。

**数字和网页端差几毛钱**
余额现在来自官方实时接口（`/v1/account/spending` 的 `balance_cny`），与网页端一致；
只有两个官方接口都不可用时才回退"最新一条已计费记录"，那种情况可能晚 1~2 分钟。

**想换账号 / Key 填错了**
运行脚本 → 明细最下面「当前 Key 尾号」那一行点进去 → 粘贴新 Key。
或者：Scriptable 里删掉脚本重建（数据也会一起重置）。

**重装 Scriptable / 换手机**
Key 和缓存都在 App 沙盒里，重装后要重新填 Key；其余数据首次运行自动重建。

**安全提醒**
Key 只存在手机本地（Keychain + App 沙盒），不会上传；但它等于账户密码——手机送修、二手出售前，先运行脚本 → 换 Key，或在 rabbitj.top 后台重置 Key。

## 八、和桌面版的功能对照

| 功能 | macOS/Windows 余额兔 | iPhone 组件版 |

| 余额 | ✅ | ✅ 主屏/锁屏/点按 |
