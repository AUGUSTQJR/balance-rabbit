余额兔 · Windows 版 1.0.4
=========================

一、这是什么
桌面上一张固定的兔子图片（蓝色圆环 · 弯弯眼，静态不眨眼）+ 余额气泡。点一下兔子就能看 rabbitj.top（anyGPT）账户的
余额、今日 / 近 7 天花费、Token 和主力模型；托盘图标常驻，默认每 10 分钟自动刷新。

二、第一次使用（重要：每个人用自己的 Key）
1. 运行「余额兔」（开始菜单或桌面快捷方式）。
2. 首次启动会弹出「设置 API Key」，粘贴以 sk- 开头的 Key，点保存。
   · Key 只保存在本机：%APPDATA%\BalanceRabbit\settings.ini（Windows DPAPI 加密）。
   · 也可以用环境变量 RABBIT_API_KEY，或放在 %USERPROFILE%\.dsh\.credentials.yaml。
3. 兔子出现在屏幕右下角，右下角托盘出现兔子图标。

三、操作
· 左键点兔子：打开 / 收起余额气泡；再点气泡内任意位置 = 刷新余额
· 按住左键拖动兔子：移动位置；拖到屏幕「左 / 右边缘」28 像素内松手 → 自动吸附成蓝色小箭头，
  点箭头弹回大兔子，箭头可沿边缘上下拖动
· Ctrl 或 Alt + 滚轮：缩放兔子（96–320）
· 右键兔子 / 托盘图标：菜单（刷新、复制余额、自动刷新、低余额提醒、开机自启、大小、
  边缘吸附、设置 API Key…、退出）
· 双击托盘图标：把兔子叫回来

四、常见问题
1. 首次运行 Windows 提示「Windows 已保护你的电脑」（SmartScreen）
   因为安装包没有购买代码签名证书。点「更多信息」→「仍要运行」即可，之后不再提示。
2. 余额显示「查询失败」
   通常是 API Key 不对或网络问题：右键 →「设置 API Key…」重填，或「刷新余额」。
3. 安装时报「访问被拒绝」
   这是 Windows 安全软件（受控文件夹访问 / 360 / 火绒 / 公司终端防护）在拦未签名程序写文件，
   不是路径问题。安装程序会自动改试 9 个位置（含程序旁的下载目录、C:\ProgramData、%TEMP%）；
   仍失败时可在提示里选「以管理员身份重新运行」。
   最稳的办法是**免安装**：直接用绿色版 zip（资源管理器右键「全部解压缩」）或单个
   BalanceRabbit.exe，放到「下载」/桌面/D 盘运行——浏览器和资源管理器是系统信任的进程，
   写文件不会被拦。
4. 设置保存不了 / 每次启动都要重填 Key
   说明 %APPDATA% 也被安全软件拦了。程序会自动改写到 exe 同目录的 BalanceRabbit-data、
   %LOCALAPPDATA%、%TEMP%；全被拦时只能内存保存（能查余额，但设置不保留），
   同时会弹托盘提示。
4. 想彻底卸载
   开始菜单 →「余额兔」→「卸载余额兔」，或：设置 → 应用 → 余额兔 → 卸载。
   卸载会保留 %APPDATA%\BalanceRabbit 下的设置（含加密的 Key），重装后不必重填；
   如需彻底清空，手动删除该文件夹即可。
5. 数据口径
   余额 = 最新一条已计费记录的 balance_cny；今日 / 近 7 天按记录时间汇总 charged_cny。
   单页最多 200 条，近 7 天超过 5000 条时气泡会提示「统计已截断」。

五、文件位置
· 程序目录：%LOCALAPPDATA%\Programs\BalanceRabbit
· 配置目录：%APPDATA%\BalanceRabbit\settings.ini
· 项目 / 充值：https://www.rabbitj.top

六、系统要求
Windows 10 / 11（x64 或 ARM64 的 x64 模拟），.NET Framework 4.8（Win10 1903+ / Win11 自带）。
