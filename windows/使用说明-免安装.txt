余额兔 · Windows 免安装版
========================

三步就能用：
1. 先建一个自己的文件夹，建议放在 D 盘等非系统盘，例如 D:\余额兔\
   把压缩包里的 余额兔-vX.Y.Z.exe 放进去再双击（X.Y.Z 是版本号，见文件名）
   （首次会弹 SmartScreen，点「更多信息」→「仍要运行」）
2. 首次运行会要求填 API Key：去 rabbitj.top 个人中心生成自己的 Key，粘贴保存
3. 桌面出现兔子，点兔子看余额；右键托盘图标有菜单

为什么不建议放桌面或 C 盘：
· C 盘 / 桌面 / 下载目录最容易被安全软件（受控文件夹访问、360、公司终端防护）拦截写入，
  程序可能存不了设置和 Key，每次启动都要重填；
· 桌面文件多、容易误删，重装系统也会一起丢。
放到 D:\余额兔\ 这种自己建的文件夹最稳，升级时把旧 exe 删掉、换成本次下载的新版本 exe 即可（设置保留）。

常用操作：
· 开机自启：右键托盘图标 → 勾选「开机自动启动」
· 换账号 / 换 Key：右键托盘图标 →「更换 API Key（换账号）…」
· 查看账户：右键托盘图标，会显示「账户 #数字」，方便确认当前 Key 属于哪个账号
· 兔子形象固定为「蓝色圆环 · 弯弯眼」的静态图片（不眨眼、不呼吸摆动），三端外观一致，没有造型切换
· 余额和每日花费优先走 rabbitj.top 官方账户接口（实时、更快），接口异常时自动回退旧方式
· 退出：右键托盘图标 →「退出余额兔」
· 菜单里若显示「接口状态：is_active = false」，只要余额能正常刷新就可以忽略
  （接口字段语义未知，不能当作账号停用；真正停用时接口会返回 403）

如果提示 Key 存不下来：
说明这台电脑的安全软件限制了写入。先把 余额兔.exe 换到 D 盘自建文件夹再试；
仍不行就只能在内存里运行（能查余额，但设置不保存），或让安全软件放行。
