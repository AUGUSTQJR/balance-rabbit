# 余额兔 · rabbitj.top 余额桌面宠物

一只常驻桌面、置顶悬浮的小兔子：点它就能看 API 余额、今日/近 7 天消费趋势、Token 用量和主力模型。
原生 macOS 应用（Swift + AppKit），不依赖 Python / Node / Electron，双击即用。

## 快速开始

```bash
open "pet/余额兔.app"          # 直接运行
# 或者
./pet/build.sh                 # 重新编译（改代码后用）
```

第一次运行会弹窗让你填自己的 `sk-` 开头 API Key（只存进本机钥匙串，按 macOS 用户隔离）。
每个用户 / 每台电脑都要填自己的 Key——填了别人的 Key 就会显示别人的余额；
升级或换人使用时启动会先问「确认账号」，菜单里也可以「更换 API Key（换账号）…」。

## 怎么用

| 操作 | 效果 |
| --- | --- |
| 左键单击兔子 | 弹出/收起余额气泡，同时刷新数据 |
| 拖动兔子 | 随意摆放，位置会记住 |
| 右键兔子 / 点菜单栏兔子图标 | 主菜单（刷新、商店、大小、自启、退出…） |
| `⌥` 或 `⌘` + 滚轮（鼠标在兔子上） | 自由缩放兔子大小 |
| 拖到屏幕左 / 右边缘松开 | 自动吸附：大兔子收起来，边缘只露出半个蓝色发光「箭头标签」 |
| 点击边缘的箭头标签 | 变回站立的大兔子，从边缘弹出来 |
| 按住箭头标签沿边缘拖动 | 指示器沿着那条边滑动 |
| 鼠标悬停 / 点击气泡柱子 | 显示「10/14 花费 ¥0.32 · 24 次」，选中高亮，再点取消 |
| 双击菜单栏金额 | 把兔子叫回当前屏幕（多屏时） |
| 菜单「把兔子放回屏幕右下角」 | 兔子跑到屏幕外时一键找回 |
| 菜单「兔子大小」 | 小 120 / 中 176 / 大 240 / 特大 300，或放大/缩小 |

气泡里显示：当前余额、今日消费、近 7 天消费（含 7 天柱状趋势图）、Token 用量、请求次数、主力模型；
余额低于阈值时数字变红、兔子头顶出现红色感叹号，并弹一条系统通知。

## 功能清单

- 点一下查余额：优先 `GET /v1/balance`（账户真实余额），接口没有时回退「最近一笔已计费请求后的余额」
- 柱状图可悬停 / 点击看当天花费与次数；气泡卡片与尖角区域命中自身，不会点穿到背后窗口
- 断网 / 接口失败时保留上一次数据，并在气泡底部提示错误
- 今日 / 近 7 天消费统计 + 趋势柱状图
- 近 7 天请求次数、Token 用量、模型分布 Top 3
- 低余额提醒（阈值可设：关闭 / ¥10 / ¥20 / ¥50 / ¥100），6 小时内不重复打扰
- 自动刷新（关闭 / 5 / 10 / 30 / 60 分钟，默认 10 分钟），唤醒后自动刷新
- 一键打开商店 / 充值页
- 兔子大小可调（96–320 pt），以底部中心为锚点缩放
- 兔子形象固定为「蓝色圆环 · 弯弯眼」的**静态图片**（`Assets/pet_sky*.png`，不眨眼/不呼吸摆动），
  三端共用同一份图，不会出现各平台绘制差异（v1.3.0 起）
- 边缘吸附：拖到左/右屏幕边缘自动换成蓝色指示器（48×48，只露一半，与兔子大小无关），
  样式固定为「箭头标签」，带呼吸光晕；悬停会往外探一点，点击变回大兔子；可沿边缘拖动；菜单里可关闭
- 开机自动启动（LaunchAgent）
- 单实例保护：开机自启 + 手动双击不会出现两只兔子
- 安装到「应用程序」文件夹（菜单里一键复制并迁移自启项）
- 菜单栏常驻小图标显示当前余额（低余额时变红）

## 数据与口径

- 主接口（v1.2.0 起）：
  - `GET /v1/account/balance` → 实时余额、`user_id`、`is_active`
  - `GET /v1/account/spending?from=YYYY-MM-DD&to=YYYY-MM-DD` → 区间汇总（请求数、花费、充值、Token）
    + 逐日明细 + 实时余额；只统计已计费请求，空天补 0
- 辅助接口：`GET /v1/usage?limit=200` 只取最近 1~2 页，用于「累计请求数」和模型分布
- 两个账户接口都不可用时，自动回退旧逻辑：翻页 7 天流水 + 最新一条 `balance_cny` 当余额
- 统计窗口：今天 0 点起，往前共 7 天；旧回退路径每页最多 200 条、最多翻 25 页（5000 条），
  超出时会显示「统计已截断」
- API Key 读取顺序：环境变量 `RABBIT_API_KEY`（调试用）→ 当前用户的钥匙串。
  **刻意不读** `~/.dsh/.credentials.yaml` 这类共享文件，避免换人使用同一台电脑时显示别人的余额。
- 新版接口 `GET /v1/balance` 返回 `balance_cny` + `user_id`；存在时用它做余额，并按 `user_id`
  过滤 `/v1/usage` 流水（管理员 Key 会带回多账户记录）。接口 404 时自动回退旧逻辑。
- 多屏 / 混合缩放：吸附、气泡都用兔子当时所在的屏幕；显示器变化后自动把兔子挪回可见区域。

## 开机自启

菜单 →「开机自动启动」会写入 `~/Library/LaunchAgents/top.rabbitj.balancepet.plist`。

⚠️ 自启项记录的是当前 app 的绝对路径。如果这个项目之后会移动/删除，
建议先右键 →「安装到「应用程序」文件夹…」，再在新位置重新勾选开机自启。

## 重新编译

```bash
cd pet
./build.sh
```

依赖：Xcode Command Line Tools（`swiftc`）。编译时会顺带生成 `build/preview/*.png` 预览图和应用图标，
产物为 `pet/余额兔.app`（ad-hoc 签名，本机运行无需额外授权）。

## 已知限制

- 窗口是透明的方形，兔子四角的空白区域也会接收点击（不影响使用）。
- 边缘吸附判定范围是距边缘 28 pt，只做左 / 右两个方向。
- 吸附指示器固定 48×48、露出 24pt（正好一半），不随兔子缩放变化；只有「箭头标签」一种样式（v1.3.0 起）。
- 吸附时大兔子窗口会隐藏，保存的位置仍是吸附前的坐标，所以重启后仍是站立的大兔子。
- 系统通知通过 `osascript` 发送，通知来源显示为「脚本编辑器」。
- 余额依赖已计费记录，若账户从未调用过模型则无法推算余额。

### 打包发给别人

```bash
./package.sh
```

会在 `dist/` 生成唯一的分发文件 `余额兔-vX.Y.Z-macOS.zip`（版本号取自 Info.plist，当前 v1.1.0），
里面只有 `余额兔.app` + `使用说明.txt`；不再单独发 app、不生成安装包。
app 是 arm64 + x86_64 通用二进制，macOS 12 以上都能跑；没有苹果开发者签名，
对方第一次打开需要「右键 → 打开」，或在终端执行 `xattr -dr com.apple.quarantine /Applications/余额兔.app`。
